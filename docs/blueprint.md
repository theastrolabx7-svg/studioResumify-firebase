# **App Name**: Resumify

## Core Features:

- AI Career Assistant Tool: Leverages generative AI to analyze user history and act as a tool to draft professional summaries, job descriptions, and ATS-optimized content.
- Multi-Step Guided Builder: A clean, interactive multi-step interface for entering personal, education, and professional details seamlessly.
- Real-time Template Preview: Instant visual feedback of resume changes across various modern and professional templates.
- Secure Database Sync: Synchronize and store user profiles and multiple resume drafts in a secure PostgreSQL database.
- High-Fidelity PDF Engine: A specialized export tool that generates print-ready, pixel-perfect A4 resumes directly from web content.
- Smart Content Extraction Tool: Use AI-powered analysis as a tool to extract text and structure from uploaded PDF resumes to quickly populate the builder.
- OAuth Authentication Suite: One-tap secure access via Google and protected email/password accounts for centralized resume management.

## Style Guidelines:

- The primary color is a deep, trustworthy Royal Blue (#2451A8), chosen for its association with professional success and corporate reliability.
- The background is a soft, airy Off-White (#F2F5F9), utilizing a desaturated version of the primary hue to maintain visual consistency while ensuring focus on the content.
- An energetic Sky Blue accent (#35C8DC) provides high contrast for primary actions and highlights, guiding the user's attention through the builder steps.
- A pairing of 'Space Grotesk' for bold, technical-looking headlines and 'Inter' for clean, neutral, and highly readable body text is used.
- A set of crisp, geometric outline icons in the primary blue to denote sections like experience, education, and certifications.
- A modular, card-based layout inspired by modern SaaS interfaces, ensuring the app remains perfectly responsive from mobile to desktop.
- Smooth, subtle transitions and horizontal slide-in effects between form steps to create a sense of progress without cognitive overload.
